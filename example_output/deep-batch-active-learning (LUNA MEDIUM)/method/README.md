# Deep Batch Active Learning by Diverse, Uncertain Gradient Lower Bounds

Reference implementation of BADGE, generated by R2C from the
following paper:

> Ash et al.. *Deep Batch Active Learning by Diverse, Uncertain Gradient Lower Bounds*.

BADGE selects a batch of unlabeled examples by clustering uncertainty-aware gradient embeddings with k-means++ seeding.

## What's in this directory

```
deep-batch-active-learning/
├── notebook.ipynb         # walks through using the package end-to-end
├── method/                # importable Python package
│   ├── __init__.py        # public API
│   ├── method.py          # the paper's contribution (the algorithm)
│   ├── model.py           # architecture
│   ├── training.py        # training procedure
│   ├── data.py            # data loading
│   └── example_data/      # smoke data downloaded on first run; drop your own .pt/.json/.csv to override

└── README.md
```

## Quick start

```bash
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```

Click **Run All**. First run downloads the smoke dataset; the full notebook
takes about 5 minutes on a laptop CPU.

## Use the package from your own code

See `notebook.ipynb` for a complete walk-through. The public API is documented
in `method/__init__.py`.

## Notes on faithfulness

This is a reference implementation, not a benchmark reproduction. The paper's
empirical comparisons are not reproduced here — the notebook runs the method
alone on a small smoke dataset to verify the implementation is correct and
shows you how to drive it.

The notebook's `params` dict makes provenance explicit: each parameter records
whether its value comes from the paper, from a system default, or was inferred.
Skim it if you want to know what's paper-faithful vs. accommodation.
